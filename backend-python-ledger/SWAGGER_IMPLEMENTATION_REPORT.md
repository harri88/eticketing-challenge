## API Endpoints Documented

### 1. Health Check
```
GET /health
Status: 200
Response: {
  "status": "healthy",
  "service": "ledger-service"
}
```

### 2. Record Payment
```
POST /api/v1/ledger
Status: 201 (Created)
Request: {
  "transaction_id": "txn-20260125-001",
  "amount": 200.00
}
Response: {
  "data": {
    "message": "Ledger entries recorded successfully",
    "transaction_id": "txn-20260125-001"
  }
}
```

Creates two balanced entries:
- Debit: Cash_Asset (money received)
- Credit: Ticket_Revenue (service provided)

### 3. Get All Ledger Entries
```
GET /api/v1/ledger
Status: 200
Response: {
  "data": [
    {
      "id": 1,
      "transaction_id": "txn-001",
      "account_name": "Cash_Asset",
      "entry_type": "DEBIT",
      "amount": 200.00,
      "created_at": "2026-01-25T10:30:00"
    },
    ...
  ]
}
```

### 4. Get Transaction Ledger
```
GET /api/v1/ledger/{transaction_id}
Status: 200 / 404
Response: Same as above (filtered by transaction_id)
```

## Code Example: Swagger Configuration

```python
from fastapi import FastAPI, Field
from pydantic import BaseModel

# Create app with OpenAPI metadata
app = FastAPI(
    title="E-Ticketing Ledger Service",
    description="Double-entry accounting ledger...",
    version="1.0.0",
    contact={"name": "E-Ticketing Team"},
    license_info={"name": "MIT License"}
)

# Define request model with documentation
class PaymentEvent(BaseModel):
    """Request model for recording a payment."""
    transaction_id: str = Field(
        ..., 
        description="Unique transaction ID",
        example="txn-20260125-001",
        min_length=1,
        max_length=50
    )
    amount: float = Field(
        ..., 
        description="Amount in AED",
        example=200.00,
        gt=0
    )

# Define endpoint with full documentation
```
